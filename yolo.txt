Creating a dedicated virtual environment (`venv` or `conda`) is the safest approach to prevent dependency conflicts between PyTorch and TensorFlow.

Installing TensorFlow alongside CUDA 13 and PyTorch can cause conflicts because PyTorch and TensorFlow bundle different versions of CUDA, cuDNN, and C++ ABI runtimes. When loaded into the same Python environment, their C++ libraries can clash and cause `Segmentation Fault` or `DLL load failed` errors.

---

### Step 1: Create an Isolated Virtual Environment

Run these commands in your terminal to create a clean, isolated environment for your YOLO and Streamlit project:

```bash
# 1. Create a new virtual environment named 'yolo_env'
python3 -m venv yolo_env

# 2. Activate the virtual environment
# On Linux / macOS:
source yolo_env/bin/activate
# On Windows (Command Prompt):
yolo_env\Scripts\activate.bat
# On Windows (PowerShell):
yolo_env\Scripts\Activate.ps1

```

---

### Step 2: Install PyTorch for CUDA 13 First

Install the PyTorch build compiled specifically for your CUDA environment. Do not install PyTorch from standard `pip` without specifying the index URL.

```bash
# Upgrade pip inside the virtual environment
pip install --upgrade pip

# Install PyTorch with your CUDA target (adjust index-url according to official PyTorch release for CUDA 13)
python -m pip install --upgrade torch torchvision --index-url https://download.pytorch.org/whl/cu128

```

---

### Step 3: Install YOLO, Streamlit, and Core Dependencies

Once PyTorch is installed, install Ultralytics, Streamlit, and your supporting libraries:

```bash
pip install ultralytics streamlit pillow numpy matplotlib transformers opencv-python Pillow av
## opencv PIL

```

---

### Step 4: Handle TensorFlow Safely

#### Do you actually need TensorFlow?

Ultralytics YOLOv8, PyTorch, Torchvision, and Hugging Face `transformers` run **100% on PyTorch**. You do **not** need TensorFlow to run YOLOv8 or standard animal detection models.

#### If you MUST use TensorFlow in the same project:

If another part of your code requires Keras/TensorFlow, install CPU-only TensorFlow to prevent it from overriding your CUDA/cuDNN driver bindings:

```bash
# Safe option: CPU-only TensorFlow to avoid CUDA runtime clashes
pip install tensorflow-cpu

```

If you require GPU support for both PyTorch and TensorFlow, run them in **two completely separate virtual environments** and communicate between them via an API (e.g., FastAPI or sub-processes).

### 2. Environment Considerations (`source=0` and `stream=True`)

Even with corrected syntax, how `source=0` behaves depends on where your virtual environment is running:

#### A. Running on a Local PC / Laptop (VS Code, PyCharm, Terminal)

* **Status:** **Will work.**
* `source=0` accesses your local webcam via OpenCV.
* Passing `stream=True` returns a Python **generator**. You must iterate through it using a `for` loop (as shown above) to actually fetch frames and run inference.

#### B. Running inside Jupyter Notebook / Google Colab

* **Status:** **Will fail.**
* `source=0` looks for a physical camera connected directly to the server executing the kernel. On cloud platforms or remote Jupyter instances, no webcam hardware exists at `/dev/video0`, causing an OpenCV `VideoCapture` error.
* `!pip install` indicates a notebook cell command; if you are in Colab, you will need to use a JavaScript webcam bridge instead of `source=0`.

### Working Streamlit Code (`app.py`)

Since you plan to use **Streamlit** as your frontend, OpenCV's `source=0` can cause blocking issues on web servers. Instead, use Streamlit's native camera input component (`st.camera_input`) inside your virtual environment:

```python
import streamlit as st
import cv2
import numpy as np
from PIL import Image
from ultralytics import YOLO

st.title("Animal & Object Detection")

# Load YOLO model
@st.cache_resource
def load_model():
    return YOLO("yolov8n.pt")

model = load_model()

# Streamlit webcam input
picture = st.camera_input("Take a picture")

if picture:
    # Convert image to OpenCV format
    img = Image.open(picture)
    frame = np.array(img)
    
    # Run YOLO detection
    results = model(frame)
    annotated_frame = results[0].plot()
    
    # Display result
    st.image(annotated_frame, channels="BGR", caption="Detected Objects")

```

Run this in your terminal inside your activated `venv`:

```bash
streamlit run app.py

```
