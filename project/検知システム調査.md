Yolo:  
・データセット：Coco(80オブジェクト)、Objects365、OpenImagesV7、

バウンディングボックス・BBOXデータプロパティ：

1. ・xywh→真ん中ポイントとサイズ（絶対ピクセル）  
   ※X,Y軸　＆　w(幅)-\> 640px & h(高さ)→402.23px  
   ※w,h→検知した物の幅と高さです。  
   ※X,Y軸→はグラフのポイント（物体の場所）  
2. ・xywhn→真ん中ポイント＆サイズ（正規化済　0.0～1.0）  
   ４軸の値を0.0から1.00に正規化されたテンソルデータ  
3. ・xyxy→角の座標(絶対ピクセル)  
   　式：\[x1,y1,x2,y2\]→上左（x1,y1）、下右(x2,y2)  
4. ・xyxyn→角の座標（正規化済 0.0～1.0）  
   式：「x(最低正規化),y(最低正規化),x(最大正規化),y(最大正規化)」  
   正規化関連の寸法（幅=820,高さ=640）  
   計算：x(正規化)＝x/幅、y(正規化)＝y/高さ  
   

ニュアンス：  
xywh,xywhn,xyxy,xyxynの意味？

１．xyxy　→　 二つ角  
→x1,y1　：：　物体の上左角  
→x2,y2　：：　物体の下右角

２．xywh　→　真ん中＋サイズ  
x,y：物体の真ん中ポイント  
w：ボックスの幅  
h:ボックスの高さ  
※物体の真ん中のポイントから40ステップ幅と60ステップの高さの至る所

３．最後のnの意味は正規化済のことです（割合）  
ｎを見たらその数値は割合に変換されます。  
0.0→０％（上や左の角）  
0.50→50％（真ん中）  
１→100％（下や右角）  
※ピクセルを変わっても割合があれば画像を拡大と縮小してもBBOXを変わらない

| `xyxy` | Property (`torch.Tensor`) | Return the horizontal boxes in xyxy format. |
| :---- | :---- | :---- |
| `xywhr` | Property (`torch.Tensor`) | Return the rotated boxes in xywhr format. |
| `xyxyxyxy` | Property (`torch.Tensor`) | Return the rotated boxes in xyxyxyxy format. |
| `xyxyxyxyn` | Property (`torch.Tensor`) | Return the rotated boxes in xyxyxyxy format normalized by image size. |
